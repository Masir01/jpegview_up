## 新增：`.gitea/workflows/build.yml`
自包含设计（旧版 `.github/**` 一行未动）：
- 只用共同子集：单标签 `runs-on: windows-latest`、`strategy.matrix`、`on: [push, workflow_dispatch]`、唯一外部 action `actions/checkout@v4`，其余全部内联 `shell: cmd` / `powershell`。
- 步骤：Checkout → `git submodule update --init --depth 1 deps/WTL-sf` → 探测 MSBuild（vswhere → `%ProgramFiles%`/`D:\Program Files` 下 `Microsoft Visual Studio\*\*\MSBuild\Current\Bin\amd64\MSBuild.exe`）→ `msbuild src\JPEGView.sln /p:Configuration=Release /p:Platform=x64` → 列出产物 → `Compress-Archive` 打包 zip 到工作区（不用 upload-artifact）。
- 路径传递用 `msbuild_path.txt` 文件而非 `$GITHUB_ENV`（避免依赖 Gitea 兼容层对 GITHUB_ENV 的支持）。
- YAML 已用 Python `yaml.safe_load` 校验通过。
- **只构建 Release|x64**：`src/JPEGView/*/lib`（32 位预编译库）不存在，只有 `lib64`。
